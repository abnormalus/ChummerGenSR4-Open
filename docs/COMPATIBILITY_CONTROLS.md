### Desktop scaling acceptance

Treat the window's logical viewport, display DPI, and accessibility text size as independent inputs. Size and reflow against the visible viewport using Avalonia measurement. Let text inherit platform typography by default, then allow content rows and their controls to grow, wrap, or scroll. Retained designer rectangles are a source inventory, and a page is only verified when its visible controls pass the runtime checks.

Run focused checks at normal and narrow widths and short heights, with long translations and larger UI text. At larger text sizes, verify labels clear their inputs, buttons remain reachable, focus can scroll to the last control, and the existing behavior survives resizing. Verify OS settings on each platform separately from simulated larger fonts. In particular, Windows Accessibility Text size and monitor scale need separate runs. macOS display scaling needs a live check, and application text enlargement needs an explicit supported mechanism where the platform does not expose a general app text-size preference.
