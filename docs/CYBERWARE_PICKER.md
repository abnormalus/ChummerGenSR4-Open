# Cyberware picker modernization boundary

This isolated stage starts from the Gear tree released in verified Nightly0.2.148. The legacy Cyberware/Bioware picker remains active. No replacement model, native window or acceptance claim exists yet.

## Contract observed in source

`frmSelectCyberware` has four production construction sites: creation and career purchases, and creation and career vehicle add-ins. The purchase paths already require explicit OK. The vehicle paths reject Cancel only; characterize actual close results before changing their policy. All four currently retain the legacy dialog without scoped disposal. Preserve the remaining creation, expense, improvement, undo and generated-weapon bodies when migrating their lifetime boundary.

Configuration includes Cyberware/Bioware mode, career mode, character essence multiplier, Basic Bioware essence multiplier, Genetech and transgenic cost multipliers, initial/locked grade, maximum capacity, subsystem-only/category restrictions, modular-plugin availability and plugin-selection context. Accepted output is canonical item name, Grade, rating, essence discount, Free, transgenic flag and AddAgain. Window ownership, source-PDF links and Cancel default must survive the adapter replacement.

Catalog choices use enabled source books. Hidden modular categories depend on AllowModularPlugins. Plugin selection additionally restricts subsystem categories and requires consuming capacity; an empty compatible catalog informs the owner and cancels. Category and grade are remembered statically. Grade availability depends on Adapsin; Cultured Bioware excludes second-hand grades. Genetech, Symbiont and Genetic Infusions request Standard, while item forcegrade can override grade selection. The existing sequence of category/item handlers can change grade enablement: capture observed results rather than infer a new rule.

Preview arithmetic is currently inside UpdateCyberwareInfo. Preserve availability suffix/localization, grade modifiers and zero floor; formula, FixedValues and Variable costs; Free; character availability test; essence rounding AwayFromZero at configured decimals; enabled Sensitive System improvements; bracketed, dual and wildcard capacity. Basic essence and grade modifiers are additive reductions. Genetech/Genetic Infusions suppress character essence modifiers; transgenic classification changes the cost path. These formulas need independent legacy expected results before delegation to a shared preview.

MaximumCapacity currently supplies a caption; do not assume it filters or rejects selections without characterization. Search has its own legacy handler and needs literal punctuation, source/category and empty-result checks before choosing shared CatalogSearch behavior.
