# PDF collection matching

Matching uses filenames without changing existing PDF links or page offsets. Exact titles outrank wildcard titles and bounded source codes. Equally strong matches remain sorted by filename; auto-match chooses the first and reports the ambiguity.

The SR4 core book additionally recognizes SR4A, Shadowrun 4A, Shadowrun 4e Anniversary, fourth-edition anniversary and 20th-anniversary variants, including compact names and punctuation differences. Anniversary matches take priority over the original fourth-edition title. Known supplement titles, other editions, character sheets, quick-start documents, errata and previews are excluded from these core aliases.

These are filename heuristics, not PDF content inspection. Review ambiguous matches before saving preferences. Regression cases live in MacSmokeTests alongside the collection-matching checks.
