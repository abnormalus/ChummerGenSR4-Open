Chummer SR4 — macOS Nightly

Requires an Apple Silicon Mac running macOS 15 or later.
Copy ChummerSR4.app to Applications, then open it.
.NET is bundled. The sourcebook PDF reader uses your local PDFs;
link each sourcebook and page offset in Chummer Settings.

This is a development preview, signed locally but not Apple-notarized.
macOS may require approval through its normal Privacy & Security controls.
Character files retain the existing Chummer format. Keep backups when
trying nightly builds and report issues with the diagnostic logs.
